# **An Interpretable and Fairness-Aware Predictive Analytics Early-Warning System for K-12 Education**

# 

# **Project Overview**

# 

# This project was developed as part of the MSIT 5910 Capstone Project course at the University of the People.

# 

# The purpose of this project is to develop an interpretable and fairness-aware predictive analytics system that helps identify K-12 students who may be at risk of poor academic performance. Unlike traditional black-box predictive models, this system incorporates explainable artificial intelligence (XAI) techniques and fairness evaluation metrics to improve transparency and support responsible educational decision-making.

# 

# The system combines machine learning prediction, SHAP-based interpretability, fairness assessment, and an interactive dashboard that enables educators to better understand student performance predictions and potential intervention strategies.

# 

# **Problem Statement**

# 

# Many educational early-warning systems focus primarily on prediction accuracy while offering limited transparency regarding how predictions are generated. This creates challenges for educators who must understand, justify, and act upon system recommendations.

# 

# This project addresses this gap by integrating:

# 

1. # Predictive analytics
2. # Explainable AI (XAI)
3. # Fairness evaluation
4. # Educator-focused decision support

# 

# into a unified K-12 analytics platform.

# 

# **Project Objectives**

# 

# The objectives of this project are to:

# 

1. # Predict student performance using machine learning techniques.
2. # Improve transparency through SHAP explanations.
3. # Evaluate fairness across prediction outcomes.
4. # Support educators with interpretable insights.
5. # Demonstrate responsible AI practices in educational analytics.

# 

# Technologies Used:

# Programming Language: Python

# Data Processing: Pandas, NumPy

# Machine Learning: Scikit-learn

# Explainable AI: SHAP (SHapley Additive Explanations)

# Visualization and Dashboard: Streamlit, Matplotlib, Seaborn

# Version Control: Git, GitHub

# 

# **Key Features**



# 

# Student Performance Prediction

# 

# Generates predictions based on student-related educational data.

# 

# Explainable AI

# 

# Uses SHAP visualizations to explain why a prediction was made and identify the factors influencing model outcomes.

# 

# Fairness Evaluation

# 

# Assesses prediction outcomes using fairness-aware evaluation metrics to support more responsible AI deployment.

# 

# Interactive Dashboard

# 

# Provides an accessible interface for exploring predictions and explanation outputs.

# 

# Results

# 

# The project demonstrates that machine learning models can be combined with explainability and fairness assessment techniques to create a more transparent educational analytics solution.
